# Six Automotive Service Websites — Project Data Package

All files and structured source data in this package are written in English. The target websites themselves should present customer-facing content in natural Russian for the local Komsomolsk-on-Amur audience.

Start with `PROMPT_FOR_CLAUDE_CODE_EN.md`. Review `data/`, all six service profiles, and `PHOTO_ASSETS_MANIFEST.json` before implementation.

Important: the photo manifest contains direct 2GIS image URLs, not local image files. Obtain permission before republishing any image on a commercial website. Prices may change and are not a public offer. Some phone numbers are masked, and Avtomaks Mobile Center has no verified price list in the available source data.
